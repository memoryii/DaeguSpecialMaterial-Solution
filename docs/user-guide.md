# 회사 담당자 사용 안내

## 분석 실행

1. 전달받은 자동 로그인 링크를 Chrome 또는 Edge에서 엽니다.
2. `Daegu_MES_quality_analysis.ipynb`를 엽니다. 커널을 선택해야 한다면 **Python (MES)**를 선택합니다.
3. **Run → Run All Cells**를 누릅니다. 1~7단계가 순서대로 실행됩니다.
4. 마지막 셀의 **결과 폴더 열기**에서 CSV·PNG·JSON을 확인합니다.

각 단계는 위에서부터 `Shift+Enter`로 실행할 수도 있습니다. 처음부터 다시 실행할 때는 **Kernel → Restart Kernel and Run All Cells**를 사용합니다.

## 데이터 관리

왼쪽 파일 목록에서 `data/`를 엽니다.

| 폴더 | 내용 | 사용할 수 있는 기능 |
|---|---|---|
| `data/` | 원본 엑셀·`analysis_config.json` | 파일 업로드·다운로드, 입력 설정 확인 |
| `data/curated/` | 전사 CSV·컬럼 매핑 | CSV 표 보기, 편집기로 열어 수정, 업로드·다운로드 |
| `data/source_images/` | 전사 근거 화면 이미지 | 이미지 미리보기, 업로드·다운로드 |
| `outputs/` | 실행별 CSV·PNG·JSON | 결과 열기·다운로드 |

파일을 더블클릭하면 열립니다. CSV는 기본 표 보기로 열리며, 직접 수정하려면 파일을 오른쪽 클릭하여 **Open With → Editor**를 선택하고 저장합니다. 새 파일은 원하는 폴더를 연 뒤 업로드 버튼으로 올립니다. 엑셀은 다운로드하여 Excel에서 확인할 수 있습니다.

기존 파일을 바꾸기 전에는 사본을 보관하세요. 분석 실행 중에는 입력 파일을 편집하지 않습니다. 분석 코드는 원본을 변경하지 않으며 실행 전후 해시로 확인합니다.

새 파일을 올리는 것만으로 분석 대상이 자동 변경되지는 않습니다. `data/analysis_config.json`의 파일명·시트 범위와 전사 CSV 형식을 함께 확인하세요. 현재 배포본은 수령한 한 작업지시의 자료를 재현하는 범위이며, 여러 작업지시의 통합 분석은 아직 지원하지 않습니다.

## 결과 해석

- 서로 다른 공정의 LOT 수량을 합쳐 고유 제품 수로 해석하지 않습니다.
- 매칭률은 제공된 기록끼리의 연결률이며, 전체 MES의 추적률은 아닙니다.
- 기록 경과시간은 실제 가동시간·공정 간 대기시간과 구분합니다.
- 최종검사 불량의 선행 LOT별 귀속과 불량 예측은 추가 데이터가 필요합니다.

세부 점검표는 결과 CSV에서 확인할 수 있습니다. 하나의 공유 Notebook이므로 여러 담당자가 동시에 실행하지 않도록 실행 순서를 조정합니다.

## 접속 문제

서버를 다시 시작하면 새 자동 로그인 링크를 받아야 할 수 있습니다. 링크가 열리지 않으면 운영자에게 실행 상태를 확인하세요. 입력 누락 오류는 표시된 파일명과 `data/analysis_config.json`을 확인합니다.
