# 회사 담당자 사용 안내

## 분석 실행

1. 운영자가 전달한 Notebook 링크를 Windows의 Chrome 또는 Edge에서 엽니다.
2. ngrok 안내가 나오면 접속을 진행합니다. Jupyter 로그인 화면에서는 운영자가 별도로 전달한 접속 토큰을 입력합니다.
3. `Daegu_MES_quality_analysis.ipynb`를 엽니다. 커널을 선택해야 한다면 Python 3을 선택합니다.
4. **Run → Run All Cells**를 클릭합니다. 또는 각 셀을 위에서부터 `Shift+Enter`로 실행합니다.
5. 마지막 셀에서 입력 파일의 실행 전후 해시 일치 여부와 저장 경로를 확인합니다.

처음에는 전체 셀 실행을 권장합니다. 중간 셀만 실행하면 앞 셀에서 만든 변수나 입력이 없어 오류가 날 수 있습니다. 다시 실행할 때는 **Kernel → Restart Kernel and Run All Cells**를 사용할 수 있습니다.

## 결과 의미

- LOT별 수량은 관측된 상세 실적의 수량입니다. 서로 다른 공정의 수량을 합쳐 고유 제품 수로 해석하지 않습니다.
- 연결 점검의 비율은 제공된 기록끼리의 매칭입니다. 전체 MES의 추적률을 뜻하지 않습니다.
- 원본 공정 집계와 상세 LOT의 집계 단위가 다를 수 있습니다.
- 화면의 시작~종료 간격은 기록 경과시간입니다. 실제 가동시간이나 공정 간 대기시간으로 바로 해석하지 않습니다.
- 최종검사 불량의 상류 LOT별 귀속을 확인할 수 없는 경우는 미확인으로 남깁니다.

## 접속·오류

- 링크가 열리지 않으면 운영자가 서버와 ngrok이 실행 중인지 확인해야 합니다.
- 로그인 토큰이 바뀌었으면 새 토큰을 운영자에게 받습니다.
- 입력 누락 메시지가 나오면 표시된 파일을 운영자에게 확인 요청합니다.
- 추가 데이터는 서버의 별도 입력 폴더에서 준비합니다. 회사 원본을 GitHub에 업로드하지 않습니다.
- 이 구성은 하나의 공유 Notebook 작업 환경입니다. 여러 담당자가 동시에 같은 Notebook을 실행하지 말고 실행 순서를 조정합니다.

분석 결과는 서버의 비공개 출력 폴더에 저장됩니다. 운영자가 필요한 CSV·PNG·JSON을 내려받아 전달할 수 있습니다.
