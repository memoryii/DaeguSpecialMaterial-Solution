# 입력 자료와 추가 데이터

이 Notebook은 MES 원본 엑셀과 화면을 옮긴 CSV를 함께 사용합니다. 스크린샷을 자동 OCR하여 생산이력을 만드는 구현은 아닙니다.

Jupyter 왼쪽의 `data/`에서 입력 자료를 관리합니다. `data/curated/`는 전사 CSV, `data/source_images/`는 전사 근거 이미지입니다. 이 폴더는 서버의 기존 `inputs/`를 연결하여 보여주며, 입력을 이중 복사하지 않습니다. Jupyter 체크포인트는 분석 표본에 포함하지 않습니다.

## 기존 자료 재실행

비공개 `inputs/analysis_config.json`에 원본 파일명, 시트 및 수기 전사 자료 경로가 들어 있습니다. 필수 파일이 없거나 컬럼 구성이 맞지 않으면 오류를 내고 중단합니다. 정상적으로 실행되면 별도 출력 폴더에 새 실행 결과가 저장됩니다.

현재 제공 형식에 대한 재현용 구현입니다. 여러 작업지시를 한꺼번에 통합 분석하는 기능은 아직 지원하지 않습니다. 동일한 이름의 엑셀만 교체하면 모든 후속 LOT 연결까지 자동 갱신된다고 가정하지 않습니다. 새로운 상세 LOT가 화면으로 제공되면 전사 CSV와 출처도 함께 업데이트해야 합니다. 새로운 입력은 별도 폴더에 보관하고 `start.sh --data-dir /absolute/private/new_inputs`로 선택합니다. Notebook을 직접 실행한다면 `MES_DATA_DIR` 환경변수로 지정합니다.

새 자료의 시트 범위와 헤더 위치가 달라지면 `analysis_config.json`의 `sheet_rules`를 수정해야 합니다. 현재 데이터에 관한 설명인 `scope_status`와 `limitations`도 검토하여 이전 설명이 그대로 남지 않게 갱신합니다.

## 추가 요청 항목

1. 「4. 작업지시 상세」와 같은 형식의 여러 작업지시 기록. 같은 품번의 정상·불량 기록과 제공 기간을 포함합니다.
2. 보충파일 시트 「2」의 화면과 같은, 공정 내에서 분리된 모든 LOT별 작업·불량 상세.
3. 공정 사이의 투입 LOT·산출 LOT·이동수량 대응 관계와 최종검사 LOT별 결과.

「작업실적내역」과 「불량등록」은 보충파일 안의 화면 이름입니다. 별도 엑셀 시트명으로 가정하지 않습니다. 연결에 필요한 지시번호·작업순서·실적순번·LOT NO를 함께 제공해야 합니다.

## 이후 확장

완전한 연결 자료와 여러 작업지시가 확보되면 LOT 이력, 설비·작업일별 불량률, 원료·배합 조건별 최종 불량 비교를 검토할 수 있습니다. 발표자료의 가상 예시는 현재 Notebook에서 실제로 수행한 기업 데이터 분석 결과가 아닙니다.
